# City Explorer – City Guide Application

City Explorer is a cross-platform application designed to help users discover interesting places, explore local attractions, and save their favorite locations.

The application was developed using .NET MAUI and C#.

## Features

- Explore places and local attractions
- Filter locations by categories (history, parks, food, culture, churches)
- View place descriptions and images
- Add and remove places from favorites
- Manage locations through an admin interface
- Add and delete places
- Store data locally using SQLite
- Switch between light and dark themes
- Multilingual interface (Estonian, English, Russian)

## Technologies

- C#
- .NET 10
- .NET MAUI
- XAML
- SQLite
- MVVM Architecture

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/OleksandraRyshniak/city_explorer.git
   ```
2. Open `CityExplorer.slnx` in Visual Studio.
3. Install the required .NET MAUI workloads.
4. Restore NuGet packages.
5. Select a supported device or emulator.
6. Build and run the application.
